# ALA. — Moda & Beauty MX

Landing page estática para la marca ALA., con una dirección visual editorial para moda y belleza.

## Tecnologías
- HTML5
- CSS incluido en la página
- Google Fonts

## Ejecutar localmente
Abre `index.html` en el navegador. Para comprobar el comportamiento en un entorno parecido al de publicación, utiliza un servidor HTTP estático local.

## Publicación
Puede desplegarse en un servicio de hosting estático. Revisa primero que las rutas de recursos, enlaces y llamadas a la acción funcionen desde la URL final.

## Lista previa a publicación
- [ ] Probar diseño adaptable en móvil y escritorio.
- [ ] Verificar enlaces, formularios y botones.
- [ ] Añadir metadatos SEO, favicon y textos alternativos.
- [ ] Optimizar imágenes y revisar accesibilidad.
- [ ] Si se agregan pagos o captura de datos, usar un backend seguro y nunca incluir secretos en JavaScript público.

## Alcance
La estructura actual muestra una página frontend; no debe describirse como tienda transaccional hasta que se verifiquen catálogo real, carrito, pagos y gestión de pedidos.
